Administrator login

The first administrator account must be created in Supabase and promoted to admin using the included setup instructions. There is no shared demo password.

Administrator controls

Lending desk

Record borrowing and returns here. Students can only view their own records on their phones.

1. Find the student

2. Choose the book

A manual entry is saved only inside this loan record. It is not added to the catalogue.

3. The student's loans

Loan history is protected: it cannot be edited or deleted. A mistake is fixed with Undo return or Edit details, which need a written reason and are saved permanently in the audit log.

Account settings

Register or update a book

Register each title once and enter its total quantity. Available copies are calculated from active loans. Increasing or decreasing total quantity will not overwrite loans.

Upload a PDF resource

PDF files are uploaded to your Supabase Storage bucket, not saved only on this phone.

Upload a dataset

Supported formats: CSV, JSON, XLSX and XLS. Each upload is saved as a new version so older copies remain available.

Registered books

Student accounts

Student account details are protected by Supabase Authentication. Admins can view registered profile names and emails, but cannot view student passwords.

OUR PURPOSE

About EDUMAK

Learning resources, made easier.

EDUMAK is a shared digital library for students and administrators. Students can find books, see their own borrowing records, due dates and countdowns online, and access PDF learning materials. Books are lent and returned by the librarian.

Librarians record borrowing and returns and manage book quantities, PDF resources and library information. Updates are stored online so authorized users on different devices see the same library records.
